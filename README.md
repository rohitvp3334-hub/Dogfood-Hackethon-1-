# 🔐 CyberShield – Intrusion Detection & Alert Dashboard

## 🚀 Overview
CyberShield is a lightweight intrusion detection system built for the DogFood Hackathon.  
It monitors logs and network activity, detects suspicious events (e.g., brute force logins, port scans),  
and raises real-time alerts through an interactive dashboard.

---

## 🎯 Problem Statement
Companies face increasing cyber threats such as ransomware, phishing, and brute force attacks.  
Detection is often slow, leading to major data breaches.  
CyberShield provides **fast detection + clear visualization** to help prevent damage.

---

## 💡 Solution
- ✅ Real-time log monitoring  
- ✅ Rule-based + ML detection of anomalies  
- ✅ Streamlit dashboard for alerts and charts  
- ✅ Dockerized setup for easy deployment  

---

## 🛠 Tech Stack
- **Backend:** Python (Pandas, Regex, Scapy)  
- **Frontend:** Streamlit  
- **Database:** SQLite  
- **Containerization:** Docker + docker-compose
